## Waterjet W1 — pressure/readiness sub-branch

A later chronology in the 2022 `Water cutter retorfit` thread establishes a real commissioning progression from unknown original process wiring through working LinuxCNC/Mesa motion and process-output integration. The machine used separate pneumatic water and abrasive functions and deliberately wired the waterjet command active-low so controller shutdown would cause the system to depressurize. The owner subsequently reported the CNC control working while independent hydraulic leaks still prevented full operation.

Preserve the distinctions:

`logical request != field polarity != pneumatic valve state != pump/pressure state`

and:

`working LinuxCNC control != healthy high-pressure hydraulic process`.

A converted FLOW waterjet additionally provides long-lived deployment evidence but not process sequencing. Its later startup failure after PC replacement was caused by a missing USB jog-controller dependency (`hal_input` readiness), demonstrating that machine availability can fail outside the high-pressure process chain.

Industrial waterjet documentation further supports a controller/pump authority split. Low-pressure piercing can be represented as a CNC request delivered to a pump PLC/controller, which then owns the physical pressure transition. OMAX process evidence also preserves recipe-dependent abrasive/water order and purge behavior. These are physical-process comparators, not LinuxCNC implementation claims.
