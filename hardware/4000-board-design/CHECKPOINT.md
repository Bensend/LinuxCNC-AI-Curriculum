## Rules frozen by BD56

- file dependency is not engineering dependency;
- consumer file unchanged does not mean consumer evidence remains current;
- small textual changes can have large evidence blast radii, and large textual changes need not stale unrelated evidence;
- invalidation follows semantic facets and typed reverse dependencies;
- historical provenance may remain valid for selected facets while being ineligible for superseded facets;
- shared-resource changes can invalidate otherwise untouched consumers;
- minimum-safe revalidation must cover every stale claim with the correct evidence class;
- preserved evidence needs an explicit equivalence reason rather than convenience;
- generated artifacts stale when supporting semantic/evidence locks stale even if generated bytes do not change;
- block evidence and board-integration evidence remain separate; and
- ordinary-control evidence receives zero personnel-safety credit without separate safety-rated authority.

## Worked-example stress test

The current OpenPressBrake FPGA/encoder state provides a concrete selective-invalidation example. Rev29 replaced the obsolete discrete proportional architecture with a two-MAX22216 shared-SPI physical contract and reduced the whole-board runtime resource model, while deliberately preserving all 18 `ENCn_A/B/Z` encoder balls. The current encoder binding follows Rev29 physical authority and its validator checks those exact balls.

Therefore the proportional rebase invalidates/supersedes proportional-resource and whole-board aggregate-resource claims, but it does not by itself invalidate the reusable AM26LV32 receiver electrical evidence or force encoder SPICE reruns. Encoder A/B/Z mapping evidence may be preserved when its exact semantic/package dependencies are demonstrated equivalent. Termination selection and encoder field +5-V remain unresolved physical/integration facts.

The retained Rev31 module source exposes the key catalog problem: it is still useful provenance for unchanged LiteX-CNC module facets but is not current production authority for proportional resources. Current Rev50 binding says so explicitly and performs a fail-closed transformation. A safe dependency graph therefore needs facet-level authority rather than whole-file `current/stale` state.
