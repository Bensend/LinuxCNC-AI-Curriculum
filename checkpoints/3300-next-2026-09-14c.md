## P3 new source-established Run From Line contract

Pinned `lib/python/plasmac/run_from_line.py` proves RFL is program-state reconstruction, not line seeking. It reconstructs prefix state including:

- units;
- path/cutter-comp/distance modes;
- parameters;
- material request and M66 material wait;
- current feed expression;
- torch start state;
- P3 torch inhibit state;
- P2 THC inhibit state;
- E3 velocity-reduction state;
- last XY/motion context.

It refuses the normal RFL build inside active cutter compensation or an unresolved subroutine context, constructs a new preamble including Z-safe positioning and optional lead-in, and then appends the selected tail.

RFL remains separate from `plasmac.comp` realtime cut recovery, which uses X/Y external offsets.

## P3 new source-established PowerMax contract

Pinned `src/hal/user_comps/pmx485.py` is a Python **userspace/non-realtime** serial component.

It separates desired and reported mode/current/pressure, exposes connection status/fault/limits/arc-time, validates replies/checksums, and after repeated communication failures drops status, closes/returns the source toward local state and permits reconnection attempts.

Do not promote `pmx485.status` to a safety witness or realtime Torch/Arc OK authority. It is a remote parameter/diagnostic communication surface.
