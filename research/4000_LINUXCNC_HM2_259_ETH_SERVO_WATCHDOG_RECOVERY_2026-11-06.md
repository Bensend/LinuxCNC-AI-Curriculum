## End-to-end cycle
The SB1001 example configures `hm2_eth` at 10.10.10.10 and a nominal 1 ms servo period, with `hm2_7i76e.0.read` preceding `motion-command-handler` and `motion-controller`, then spindle/PID logic and `hm2_7i76e.0.write`. In `hostmot2.c`, read requests transfer FPGA registers, `hm2_read` processes watchdog/GPIO/encoder/stepgen readback into HAL pins, and `hm2_write` prepares the watchdog reset word, GPIO, PWM and stepgen registers, transmits queued writes, updates changed parameters, and finishes the transport write. A new motion command cannot reach the FPGA through this scheduled write path before that write invocation. The hardware application and actual packet latency are not established by ordering alone.

**Two distinct failure boundaries:** `hm2_eth.c` read reception computes a deadline from `packet-read-timeout`: <=0 selects 80% of thread period, values 1..99 are percentage of thread period, with a 100,000 ns minimum. Failed reception records a soft error and can return `-EAGAIN`; `hostmot2.c` explicitly treats `-EAGAIN` as a temporary read failure and skips processing that read. A soft packet loss is therefore not automatically a watchdog bite. A persistent communication error sets the low-level `io_error` boundary, at which read/write functions stop.

**Watchdog:** `watchdog.c` exports `watchdog.has_bit` and `watchdog.timeout_ns`, initializes the timeout to 5,000,000 ns, and prepares reset word `0x5a000000` on every write. The first normal watchdog write enables it. Timeout setting is derived from FPGA clock counts; the code warns when configured timeout is less than 1.5 times the write period. A bite latch blocks normal watchdog update until reset; communication error likewise blocks writes. After clearing the relevant state, the driver checks `needs_reset`/`needs_soft_reset`, force-writes FPGA configuration and reports recovery success/failure. **Clearing a HAL error is not proof that the machine can safely resume motion**: position trust, servo state and independent personnel-safety authority remain separate.

The Ethernet transport's `hm2_eth_reset` deliberately sends a packet requesting a watchdog bite. Do not mistake this for a routine motion-enable or safe-restart command. The exact conditions under which `needs_reset` is asserted, and how FPGA outputs respond to watchdog expiry, require a deeper trace and actual bitstream/hardware evidence.

**Stepgen scaling:** `stepgen.c` computes position feedback from FPGA accumulator subcounts divided by 65536 and HAL `position-scale`. It corrects a near-zero scale to +/-1 and limits requested max velocity against configured step timing and clock capacity. Treat stepgen's own position estimate as generated-step feedback, **not** independent motor encoder proof.

## Minimal inspection exercise (no machine actuation)
1. Pin LinuxCNC v2.9.10 and inspect the four source files above; verify the named functions and blob hashes with `git rev-parse v2.9.10:src/hal/drivers/mesa-hostmot2/<file>`.
2. Inspect the SB1001 INI-selected nested HAL and confirm `loadrt hm2_eth`, `addf ...read`, `addf motion-controller`, `addf ...write` and `SERVO_PERIOD`; verify no similarly named parent HAL was substituted.
3. In an isolated LinuxCNC/Mesa test fixture, with motor power disconnected and independent safe state confirmed, collect `halcmd show thread`, `halcmd show pin hm2_7i76e.0.watchdog.has_bit`, `halcmd show param hm2_7i76e.0.watchdog.timeout_ns`, `halcmd show pin hm2_7i76e.0.io_error` (verify pin availability/version first), and packet error counters/timeouts. Record baseline; do not deliberately drop packets on a live machine.
4. **Predictions to check:** (P1) a single recoverable read loss may skip one HAL readback without immediately asserting watchdog.has_bit; (P2) a persistent io_error suppresses normal read/write; (P3) a watchdog bite persists until a deliberate recovery sequence; (P4) reducing timeout below 1.5 servo periods produces a warning when changed. All are **unexecuted**; transport and FPGA conditions may alter observations.
5. Distinguish a software/transport watchdog from an independently validated safety-rated stop. Do not use a production machine to test recovery.
