The redesign preserves the immutable S04 gates:

- same pinned LinuxCNC revision;
- same `MIN_FERROR=0.010`, `FERROR=0.100`, velocity limit and moving command;
- runtime `joint.0.f-error-lim` remains the threshold oracle;
- same stock realtime `abs` + `comp` strict-crossing instrumentation;
- stationary feedback is held at an already-equal command/feedback value for at least 250 servo cycles;
- stationary case must show no comparator crossing/over-limit state, no following error, no joint error, retained motion/amp enable, and zero sampler overruns;
- moving case must retain the predeclared remaining-travel gate and fault/disable observations.

Running the control first is scientifically preferable here: the moving case intentionally faults/disables the controller and therefore contaminates a same-runtime stationary test if performed afterward. The control-first ordering avoids both that state contamination and the failed fresh-runtime lifecycle dependency.
