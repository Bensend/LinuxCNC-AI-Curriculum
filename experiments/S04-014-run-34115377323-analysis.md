## Why exit 22 does not reject the prediction

The wrapper correctly added `rt_crossed` as the authoritative strict-crossing oracle, but it accidentally retained the legacy base-script gate:

```text

```

`crossed` is computed from decimal text exported by `halsampler`; the previous S04 run had already shown that this representation can print both values as `0.05` at the critical cycle even though production motion asserts the fault. The entire purpose of the realtime `comp` redesign was to eliminate that rounding ambiguity.

Therefore run `34115377323` failed because the wrapper simultaneously required the new realtime oracle **and** the obsolete rounded-text oracle. That contradicts the stated redesign, not the immutable experiment plan. The immutable Gate B requires evidence that `abs(joint.0.f-error)` grows past runtime `joint.0.f-error-lim`; it does not require that a rounded textual representation preserve the strict inequality.
