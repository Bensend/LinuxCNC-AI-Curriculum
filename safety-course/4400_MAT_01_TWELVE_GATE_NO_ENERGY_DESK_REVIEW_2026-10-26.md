# MAT-01 — Twelve-gate documentary verification (BLANK / NOT RUN)

**Purpose:** a qualified engineer can use this **no-energy documentary** checklist to determine what must be obtained before physical validation. It is not a test procedure or machine approval. Do not change live DIP switches, defeat mats, enter an energized hazard, or run a press brake as part of this review.

| Gate | Evidence to collect / exact question | Result |
|---|---|---|
| MAT-G01 — Applicability | Does selected machine actually have mats? Exact manufacturer, part/serial, manual revision, machine lifecycle and risk-assessment scope. | NOT RUN |
| MAT-G02 — Zone map | Signed floor plan for each mat, channel and sensor boundary; all access routes, door openings and alternative footholds. | NOT RUN |
| MAT-G03 — Detection scope | Product-specific assured person/actuation limits; lighter people, tools, supported postures and wear assumptions. | NOT RUN |
| MAT-G04 — Config baseline | Enabled/disabled channels, redundant DIP settings where applicable, mode selection, firmware/config provenance and change authorization. | NOT RUN |
| MAT-G05 — Individual witness | For each physically installed zone, which independent documented input/indicator maps to it? Disabled/off status not misread as healthy. | NOT RUN |
| MAT-G06 — Geometry | Can anyone reach, step over, under, around, onto a baseplate, trough or recessed pocket without actuation? Guard/trim evidence. | NOT RUN |
| MAT-G07 — Environment/HF | Swarf, oil, washdown, cable wear, slip/trip, cleaning access, easy correct reinstall and predictable defeat incentives. | NOT RUN |
| MAT-G08 — Stop chain | Safety-related sensor/controller/final-element diagram, no ordinary LinuxCNC/HAL or non-safety auxiliary promoted to safety authority. | NOT RUN |
| MAT-G09 — Physical end state | Machine-specific stopping/holding and residual-energy proof method planned by qualified personnel; Y1/Y2 and hydraulic isolation separately addressed. | NOT RUN |
| MAT-G10 — Reset/rearm | Manual/auto mode, power-dip behavior, visible reset or supplementary occupancy detection, separate fresh start, no latched motion resume. | NOT RUN |
| MAT-G11 — Change control | Affected BND/ENE/HAZ/SF/PHY/SRS/DEP/ARC/HF/VAL/PT/CHG/RR/UNK links; old evidence marked STALE. | NOT RUN |
| MAT-G12 — Release/evaluation | Qualified independent documentary signoff, physical proof gate G0/G1, external blind learner evaluation and residual risk recorded. | NOT RUN |

**Disposition:** all 12 NOT RUN. Any unknown that affects personnel exposure is **HOLD**, not conditional PASS. A desk review cannot establish physical safety. No pressure threshold, stop distance, PL/SIL, controller wiring, selected mat presence, or OpenPressBrake authorization is asserted. **No personnel-exposed operation; experimental operation only isolated/remote with people outside the danger zone and residual risk explicitly reviewed.**
