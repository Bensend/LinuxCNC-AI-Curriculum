## Instrumentation diagnosis

Pinned `control.c` sets the following-error flag only when the internal double-precision `abs(ferror) > ferror_limit` predicate is true. The simultaneous presence of `joint.0.f-errored` plus a maximum textual sample of exactly `0.05` versus `0.05` indicates that the text sampler representation is not a sufficient oracle for the strict floating-point predicate at the transition. Treating the flag alone as a replacement would weaken the immutable predeclared gate after seeing results, so this run remains failed for acceptance.

## Material redesign

The next attempt adds an independent realtime observation path after `motion-controller`: pinned stock `abs` computes `abs(joint.0.f-error)` and pinned stock `comp` with zero hysteresis compares that value against `joint.0.f-error-lim`. `comp.out` is TRUE exactly when its `in1 > in0`. The comparator bit is sampled in the same servo thread before the sampler, avoiding dependence on decimal text precision while leaving production motion source unchanged.

This is a harness/instrumentation redesign, not a changed acceptance criterion. The original textual values remain captured for magnitude/context; the new comparator bit is the cycle-level strict-crossing oracle.
