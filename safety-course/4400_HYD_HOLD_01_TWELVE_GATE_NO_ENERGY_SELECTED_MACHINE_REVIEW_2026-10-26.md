# HYD-HOLD-01 — Twelve-gate qualified documentary review
**BLANK / NOT RUN.** This is a no-energy review of existing documentation, not a test or hydraulic service procedure. Do not perform live line-break, pressure release, ram-drop or bypass tests from this worksheet.

For each gate record **PASS / FAIL / UNKNOWN / N/A with qualified basis**, exact drawing revision, evidence location, reviewer, date and open corrective action. Missing proof is UNKNOWN, never presumed PASS.

| Gate | Required existing documentary witness | Result |
|---|---|---|
| 1. Machine identity | Selected press-brake revision and risk assessment | NOT RUN |
| 2. Axis load path | Y1/Y2 independent gravity/load and mechanical support paths | NOT RUN |
| 3. Circuit drawing | As-built cylinders, directional valves, holding valves, pilots, returns | NOT RUN |
| 4. Exact valve option | Part numbers, model codes, manual-release and override states | NOT RUN |
| 5. Mounting/failure zones | Hose/pipe segments on both sides of each holding valve | NOT RUN |
| 6. Power loss | Risk-derived protective stop and load-hold strategy | NOT RUN |
| 7. Common causes | Shared pilot, common drain, accumulators, thermal/pressure effects | NOT RUN |
| 8. Functional monitoring | Independent safety logic, valve/pressure diagnostics, fault response | NOT RUN |
| 9. Personnel access | Guards, mechanical supports, service access and rescue | NOT RUN |
| 10. Isolation | Qualified energy-isolation and trapped-pressure zone map | NOT RUN |
| 11. Change control | Correct valve substitution/replacement/release restoration records | NOT RUN |
| 12. Fresh rearm | Independent reset, zone clear and deliberate local start authority | NOT RUN |

**Decision:** all gates unexecuted; **G0/G1 HOLD**, no personnel-exposed operation. A qualified reviewer may mark a specific valve option N/A only after evidence it is absent; no machine-specific hydraulic truth table, stop distance, PL/SIL or diagnostic coverage is inferred. Actual validation is separate, with controlled safe conditions and independent authorization.
