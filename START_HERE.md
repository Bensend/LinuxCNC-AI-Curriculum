# Start Here — LinuxCNC AI Curriculum

This is the entry point for every new AI work session.

## Required Action

1. Read `MASTER_MISSION.md` completely and treat it as the standing mission contract.
2. Read `CURRICULUM.md`, `SOURCE_POLICY.md`, `MODULE_TEMPLATE.md`, and `PROGRESS.md`.
3. Inspect the latest laboratory results and existing artifacts relevant to the current/next module.
4. Recover any unfinished checkpoint or newly spawned prerequisite from repository state.
5. Execute the highest-priority unblocked curriculum work according to `MASTER_MISSION.md`.
6. Perform substantive work now. Do not respond with only a plan, summary, or request for permission to continue.
7. Commit durable results, update progress, and preserve an unambiguous next-work checkpoint before ending the session.
8. Follow the perpetual lesson scheduling rules in `MASTER_MISSION.md`. If scheduling requires an owner action that the current environment cannot perform, ask only for that minimum action.

## Minimal Human Launch Prompt

The owner should be able to start or resume the course with:

> Go work on the LinuxCNC curriculum. Read `START_HERE.md` in `Bensend/LinuxCNC-AI-Curriculum` and follow it.

Repository state, not chat history, determines what lesson comes next.
