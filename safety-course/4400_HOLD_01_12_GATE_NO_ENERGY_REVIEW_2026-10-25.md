# HOLD-01 — Twelve-gate no-energy hydraulic stop/hold/recovery desk review
**Review design only | ALL GATES NOT RUN | 2026-10-25**

A qualified engineer may apply these documentary gates to a *restricted* as-built machine file. Do not energize the machine, open pressure lines, move the ram, adjust relief valves or touch a sealed manual lowering screw as part of this course.

| Gate | Documentary review question | Current |
|---|---|---|
| D01 | Exact machine identity, Y1/Y2 load/mode/access map and applicable press-brake standards recorded? | NOT RUN |
| D02 | Exact installed hydraulic valve OEM, part suffix, revision and orientation independently identified? | NOT RUN |
| D03 | Cylinder-side vs hose-side protected segment mapped without assuming check/fuse location? | NOT RUN |
| D04 | Pilot, vent, return, relief and manual-override paths traced to real chambers and pressure zones? | NOT RUN |
| D05 | Normal control, independent safety-control, final-element and physical restraint authorities separated? | NOT RUN |
| D06 | Loss of pilot, power, pressure and common feeds analyzed without guessed hydraulic truth table? | NOT RUN |
| D07 | Relief/shock, thermal, seal/leak and asymmetrical Y1/Y2 failure cases included? | NOT RUN |
| D08 | OEM emergency lowering instructions and restoration/locking authority obtained, with no generic transfer? | NOT RUN |
| D09 | Tool-change/rescue/maintenance tasks have physical support and task-specific isolation/LOTO plans? | NOT RUN |
| D10 | Guards, E-stop, fault reset, manual override restoration and fresh deliberate start independently specified? | NOT RUN |
| D11 | Future **non-personnel-exposed** qualified G1/G2 witness method and abort/containment defined before any live test? | NOT RUN |
| D12 | Independent reviewer records contradictions, UNKNOWNs, change-control invalidations and HOLD/release decision? | NOT RUN |

**Decision logic:** an UNKNOWN safety-critical path, missing owner, unreconciled part variant, incomplete rescue or no independent physical stop/hold witness means **HOLD**. Completing desk review does not authorize energized tests or personnel exposure. G0/G1 HOLD, G2 NOT RUN, G3/G4 NOT AUTHORIZED, G5 HOLD until qualified machine-specific evidence and approval. This is not a pass/fail report and creates no TEST-CONFIRMED claim.
