# 4400 BLACKOUT-01 — visible egress after power loss: practical technician card

**Status:** NON-GRADUATED; **8 public PAPER scenarios UNSCORED**, **8 documentary gates NOT RUN**. No live blackout, occupancy or hazardous machine test. [Original OSHA/EUCHNER/Pilz source audit](../research/4400_BLACKOUT_01_OSHA_EUCHNER_EGRESS_LIGHTING_ESCAPE_POWER_LOSS_AUDIT_2026-10-26.md).

**One-minute lesson:** an escape-release handle, an unlocked door and an illuminated exit route are **three different propositions**. A machine can stop electrically but retain a gravity hazard; a spring-locked door can remain locked after a blackout; a tool-free release can be impossible to find or use in the dark or under actuator tension. Workplace exit-route requirements do not automatically define cell-interior lighting specifications.

## Eight paper cases — UNSCORED

| ID | Situation | Required reasoning |
|---|---|---|
| BLK-P01 | CNC and guard lighting lose power; spring-locked gate remains shut. | Identify mechanical inside escape, complete egress path and gravity/energy hazards, not HMI unlock. |
| BLK-P02 | Emergency exit sign is lit but cell interior is dark. | Distinguish regulated exit route from risk-assessed cell-interior visibility and route to exit. |
| BLK-P03 | Red escape handle is hidden behind a portable worktable. | Correct physical reachability/maintainability; do not bypass the lock. |
| BLK-P04 | Guard actuator is under tensile load and escape release does not move freely. | Exact OEM manual mounting/load caveat; physical nonhazardous proof and correction before use. |
| BLK-P05 | HMI reports `SAFE` while a supported ram has trapped pressure. | Separate status from actual Y1/Y2 stop/hold and energy-isolation witness. |
| BLK-P06 | Maintenance leaves a cable across the only evacuation path. | OSHA covered exit-route obstruction, plus selected-machine whole-body egress plan. |
| BLK-P07 | Power returns and old remote start/pedal remains asserted. | No automatic restart; deliberate independent rearm and fresh operator command. |
| BLK-P08 | Crew wants to defeat guard locking permanently because escape is difficult in darkness. | Improve accessible mechanical escape and visibility/lighting, preserve safety function and revalidate. |

## Eight documentary gates — NOT RUN

| Gate | Required selected-machine evidence |
|---|---|
| BLK-G01 | Actual enclosure/whole-body entry, persons at risk, exit-route and cell boundary; N/A if not applicable |
| BLK-G02 | Exact installed guard-lock and escape-release part/manual/variant and mounted access geometry |
| BLK-G03 | Mechanical release usability, actuator loading and unobstructed escape path assessment |
| BLK-G04 | Ordinary/safety/emergency-lighting power dependency and loss/restoration states |
| BLK-G05 | Workplace exit-route regulatory applicability and site emergency plan, distinct from machine-interior assessment |
| BLK-G06 | Actual Y1/Y2 gravity/load restraint, hydraulic isolation and independent physical safe-state proof |
| BLK-G07 | Qualified no-hazard commissioning inspection and change/maintenance revalidation, not an occupied blackout drill |
| BLK-G08 | Independent evaluator and owner release decision with all UNKNOWNs preserved |

**Minimum floor:** no personnel-exposed hazardous operation until the machine-specific safe-to-operate threshold is independently established. Isolated/remote work must keep people outside the danger zone; never lock a person inside for a test. The eight cases are public practice, not hidden or scored competency evidence.
