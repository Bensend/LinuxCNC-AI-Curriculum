# Authoritative Curriculum Level Order

This file resolves curriculum level numbering and supersedes older level-numbering prose that may remain in historical or standing documents.

The active level order is:

- **1000 — LinuxCNC foundations**
- **2000 — advanced control and diagnostics**
- **3000 — machine-specific specialization**
- **4000 — hardware and AI-assisted implementation**

Machine-specific tracks are numbered 3100–3900. In particular, **Press Brakes are 3600**.

Reusable controller hardware, HostMot2/FPGA development, Ethernet/control-board architecture, reusable I/O and motion-interface blocks, safety-oriented hardware boundaries, circuit/logic simulation and fault testing, and AI-assisted schematic/PCB/EDA workflows belong primarily in the **4000 series**.

`CURRICULUM.md` contains the detailed active definitions. If older text in `MASTER_MISSION.md`, historical research artifacts, experiment names, commit messages, or retained evidence uses the former 3000/4000 numbering, preserve the historical artifact for provenance but interpret future work using this file and `CURRICULUM.md`.

Do not rename historical experiment IDs or evidence files solely because of this numbering change. New progress/checkpoint language must use the active numbering.
